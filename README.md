# Student Management System

A beginner-friendly Student Management System built with **HTML, CSS, and JavaScript**. It lets you manage student records in your browser without installing a database.

## Features

- Add student records
- Edit existing student details
- Delete records after confirmation
- Search by name, roll number, email, or course
- View total students and number of courses
- Save records in browser `localStorage`
- Responsive layout for desktop and mobile
- Prevent duplicate roll numbers

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add a student using the form.

No installation or build tools are required.

## Note

This is a front-end learning project. Data is stored only in the browser where it was entered. It does not include user login, a server, or a shared database.
